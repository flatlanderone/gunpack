# Quieter (Silenced) Vanilla Weapons for Streamers and People Playing Without Headphones - version 3.2.0.100/3.2.0.1.0.0

## Overview
This modlet changes the shooting sound of all vanilla firearms and weapon-based turrets to a quieter version, identical to the sound used when a silencer is equipped. Great for streaming and playing without headphones.

## Important: Do not use alongside Flatlander's Combat Sandbox for IZY Classic

Do not install this mod if you have [Flatlander's Combat Sandbox for IZY Classic](https://www.nexusmods.com/7daystodie/mods/9980), as **Combat Sandbox** already lets you play with silenced vanilla and IZY Classic weapons (see the 6. Misc . Options tab).

## Requirements
 - 7 Days to Die v3.0 and later. 

## Manual installation

 1. Download the mod file.
 2. Unzip it anywhere on your hard drive.
 3. Copy the zzzSilencedWeaponsFLTR folder to the 7 Days to Die Mods folder. The default location is **%APPDATA%\7DaysToDie\Mods**. 
 4. If you are updating the mod, delete the folder with the old version.
 5. The mod must load after any mods that modify vanilla weapon sounds.
 
## Important notes

 1. Adding the mod to an existing save is safe, but you should always make a backup of your game save.
 2. Removing the mod is safe.
