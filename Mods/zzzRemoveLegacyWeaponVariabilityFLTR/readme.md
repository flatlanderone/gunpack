# Remove Magnitude v3.2.0.1.0.0  

## Overview
This modlet disables the magnitude system (stats) for all vanilla and custom weapons and tools. I use it as a modding utility to work on weapon mods. Use it at your own risk in normal playthroughs!

## Requirements
 - 7 Days to Die v3.x. 
 - A new save.

## Manual installation

 1. Download the mod file.
 2. Unzip it anywhere on your hard drive.
 3. Copy the **zzzRemoveMagnitudeFLTR** folder to the 7 Days to Die Mods folder. The default location is **%APPDATA%\7DaysToDie\Mods**. 
 4. If you are updating the mod from a previous version, delete the entire folder with the old version.
 5. The mod must load after any mod that adds weapons and tools.
 
## Important notes

 1. It is recommended to install this mod BEFORE starting a new save. 
 2. Items found before the mod is installed will retain the stats derived from the Magnitude system.
 3. Removing the mod is probably safe, but you should always make a backup of your game save.
 4. The mod removes all stats blocks. This may lead to unexpected results in future versions of the base game.
